Nested List Spacing Remediation

Diagnosing and eliminating unwanted browser default margins around paragraph and nested list elements within ordered lists.

Root Cause of Extra Highlighted Space:

  • Browser Default Paragraph Margins: Browsers apply default margin-top: 1em; and margin-bottom: 1em; (typically 16px) to <p> tags.
  • Browser Default List Margins: Browsers apply default margin-bottom: 1em; on the first <ul> and margin-top: 1em; on the second <ul>.
  • Fix: Apply style="margin: 0;" to the intermediate <p> and reset top/bottom margins on the adjacent nested <ul> tags, eliminating the vertical gaps completely.
