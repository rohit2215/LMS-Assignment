### Question 1 [1 Point]
**Which HTML tag is used to create a hyperlink?**
- a. `<p>`
- **b. `<a>` [Correct Answer]**
- c. `<b>`
- d. `<br>`

> **Explanation:** The `<a>` (anchor) tag combined with the `href` attribute defines a hyperlink connecting web pages, files, or locations within a page.

---

### Question 2 [1 Point]
**What tag is used to render an image on a webpage?**
- **a. `img` [Correct Answer]**
- b. `src`
- c. `image`
- d. None of the above

> **Explanation:** The `<img>` tag is the standard HTML void element used to embed images. `src` is an attribute of the tag, not the element itself.

---

### Question 3 [1 Point]
**Which HTML tag is called the root element of an HTML document?**
- **a. `<html>` [Correct Answer]**
- b. `<body>`
- c. `<title>`
- d. `<head>`

> **Explanation:** The `<html>` element is the top-level root element containing all other HTML tags (head, body, etc.) in an HTML document.

---

### Question 4 [1 Point]
**What is meant by an empty tag in HTML?**
- a. There is no such concept of an empty tag in HTML
- **b. An empty tag does not require a closing tag [Correct Answer]**
- c. An empty tag cannot have any content within it
- d. None of the above

> **Explanation:** In HTML, empty tags (also known as void elements such as `<img>`, `<br>`, `<hr>`, `<input>`) cannot contain child nodes and do not require a closing tag.

---

### Question 5 [1 Point]
**Which of the following is correct about HTML?**
- a. HTML uses User Defined Tags.
- **b. HTML uses tags defined within the language. [Correct Answer]**
- c. Both A and B.
- d. None of the above.

> **Explanation:** HTML is a standardized markup language with predefined tags established by W3C/WHATWG specifications. Unlike XML, developers cannot invent arbitrary tags.

### Question 7 [1 Point]
**The “`<h1>`” tag is used for the smallest heading style.**
- a. True
- **b. False [Correct Answer]**

> **Explanation:** `<h1>` designates the highest level and largest heading style. `<h6>` represents the smallest heading style.

### Question 8 [1 Point]
**The “`<caption>`” tag is used for _____________________.**
- a. defines a page caption
- b. defines an image caption
- **c. defines a table caption [Correct Answer]**
- d. None of the above

> **Explanation:** The `<caption>` element is specifically defined in HTML to provide a title or accessible description for a `<table>` element.

### Question 9 [1 Point]
**Which of the following is true about HTML tags?**
- a. Are case sensitive
- **b. Are not case sensitive [Correct Answer]**
- c. Are in uppercase
- d. Are in lowercase

> **Explanation:** HTML tags are case-insensitive by specification (e.g., `<DIV>` and `<div>` are parsed identically), although lowercase is standard industry practice.

### Question 10 [1 Point]
**Which of the following properties is used to change the font of text?**
- **a. `font-family` [Correct Answer]**
- b. `font-size`
- c. `text-align`
- d. None of the above
