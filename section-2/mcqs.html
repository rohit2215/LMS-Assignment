Section II: Multiple Choice Questions

Theoretical knowledge assessment covering core HTML elements, tags, attributes, and basic CSS properties (Total: 10 points).

1

Which HTML tag is used to create a hyperlink? [1]

  • a. <p>
  • b. <a> Correct Answer
  • c. <b>
  • d. <br>
Explanation: The <a> (anchor) element with the href attribute defines a hyperlink connecting one web page or document to another.
2

What tag is used to render an image on a webpage? [1]

  • a. img Correct Answer
  • b. src
  • c. image
  • d. None of the above
Explanation: The <img> tag is the standardized HTML element used to embed images. The src is an attribute specifying the image URL, not the tag name itself.
3

Which HTML tag is called the root element of an HTML document? [1]

  • a. <html> Correct Answer
  • b. <body>
  • c. <title>
  • d. <head>
Explanation: The <html> element represents the root of an HTML document, enclosing all other elements (except for the <!DOCTYPE html> declaration).
4

What is meant by an empty tag in HTML? [1]

  • a. There is no such concept of an empty tag in HTML
  • b. An empty tag does not require a closing tag Correct Answer
  • c. An empty tag cannot have any content within it
  • d. None of the above
Explanation: In HTML standards, empty tags (void elements such as <img>, <br>, <hr>, <input>) do not require and must not have a closing tag.
5

Which of the following is correct about HTML? [1]

  • a. HTML uses User Defined Tags.
  • b. HTML uses tags defined within the language. Correct Answer
  • c. Both A and B.
  • d. None of the above.
Explanation: HTML utilizes standardized tags defined strictly by the W3C language specification (unlike XML, which allows developers to define custom user tags).
6

Survey has one/more correct answer [1]

  • a. True Correct Answer
  • b. False
Explanation: In LMS assessment and feedback platforms, survey items can be designed as single-selection questions or multi-select/multi-response questionnaires.
7

The “<h1>” tag is used for the smallest heading style. [1]

  • a. True
  • b. False Correct Answer
Explanation: <h1> designates the highest-level and largest heading style. <h6> represents the smallest heading style.
8

The “<caption>” tag is used for _____________________. [1]

  • a. defines a page caption
  • b. defines an image caption
  • c. defines a table caption Correct Answer
  • d. None of the above
Explanation: The <caption> element is reserved specifically in HTML to define the title or accessible caption of a <table> element. (Image captions use <figcaption>).
9

Which of the following is true about HTML tags? [1]

  • a. Are case sensitive
  • b. Are not case sensitive Correct Answer
  • c. Are in uppercase
  • d. Are in lowercase
Explanation: HTML tags are case-insensitive according to the HTML specification (e.g., <DIV> and <div> are treated identically), though lowercase is recommended for clean coding standards.
10

Which of the following properties is used to change the font of text? [1]

  • a. font-family Correct Answer
  • b. font-size
  • c. text-align
  • d. None of the above
Explanation: In CSS, the font-family property sets the typeface/font of text elements. (font-size alters size, and text-align controls alignment).
